Analog zu der Konvergenz der reellen Zahlen konvergierte eine komplexe Folge $(a_{n})_{n \in \mathbb{N}} \in \mathbb{C}$ genau dann, wenn gilt {{c1::$\exists \epsilon > 0\exists n_{0} \in \mathbb{N} \forall n \geq n_{0}: | a_{n} - a | < \epsilon$}}
<!--ID: 1771685265697-->


Die Konvergenz von einer komplexen Folge lässt sich zeigen, indem man {{c1::die Konvergenz des Realteils}} und {{c1::die Konvergenz des Imaginärteils}} zeigt. 
<!--ID: 1771776983247-->

$\lim_{ n \to \infty } a_{n} = a \iff$ {{c2::$\lim_{ n \to \infty } \mathrm{Re}(a_{n}) = \mathrm{Re}(a) \land \lim_{ n \to \infty } \mathrm{Im}(a_{n}) =\mathrm{Im}(a)$}}
<!--ID: 1771685265701-->

Die Grenzwertsätze gelten für komplexe Folgen {{c1::ohne Einschränkungen analog zu den reellen Zahlen}}
<!--ID: 1771685706668-->

$\lim_{ n \to \infty } |a_{n}| = 0 \implies$ {{c1::$\lim_{ n \to \infty }a_{n} = 0$}}
